# Bonjour — 프랑스 여행 금융 도우미

`dist/index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치가 필요하지 않습니다.

- 여행 일정 검증 및 카드 유무에 따른 안내
- 위치·카드·도보 범위에 따른 가상 ATM 비교
- 같은 매장·같은 날 영수증 합산과 데모 환급 계산
- 지출 추가·삭제, 예산 계산, 도넛 차트
- 여행 금융 전용 규칙 기반 채팅

여행 설정, 영수증, 가계부는 브라우저 localStorage에 저장됩니다.
실시간 금융 데이터, 실제 AI, OCR, 은행 연결은 포함하지 않습니다. ATM 및 환급 수치는 시연용입니다.
