# TravelBack AI — 여행의 모든 금융, 가볍게

`dist/index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치가 필요하지 않습니다.

- **나의 여행:** 국가·도시·기간·원화 예산·카드·외화계좌 설정, 맞춤 금융 가이드와 우리금융 공식 링크
- **환전·ATM:** 자연어 금액 파싱, 동일 현금 수령액의 ATM·환전소·외화충전 비용 비교, 거리 필터, 가상 지도, 양방향 환율 계산, 환율표 사진 미리보기 및 직접 확인한 조건 적용
- **택스 리펀드:** 영수증 이미지/PDF 첨부, 수동 거래 확인, 매장·날짜 합산, 서류·자격 확인, 결제 수단 × 환급 장소 × 수령 방식의 실지출액 비교, 최종 EU 출국 경로 및 체크리스트
- **여행 가계부:** 영수증 연결 및 중복 방지, 지출·자금 이동 구분, 카테고리 추정, 예산·소비 차트, 환급 예정/실제 수령 관리, 금융 리포트와 텍스트 다운로드
- 모든 페이지에서 여행 설정 및 선택 영수증을 참조하는 규칙 기반 채팅, 모바일·태블릿 대응

여행 설정·거래는 `travelback-finance-v2` localStorage에 저장합니다. 기존 `bonjour-finance-v1` 기록은 처음 실행할 때 옮기며 원본 키는 유지합니다. 첨부 파일은 로컬 미리보기만 제공하고 서버에 전송하지 않습니다.

프랑스·일본·태국의 환율/현금 확보를 시연하며 택스 리펀드 계산은 프랑스에 한정합니다. 실시간 금융 데이터, 생성형 AI, OCR, 실제 위치·길찾기, 은행·카드 연결은 없습니다. 표시된 환율·수수료·환급률·장소·영업시간은 시연 가정입니다. 실제 지원이 미확인인 매장/시내 환급은 제외합니다.

`dist/core.js`의 일반 계산 엔진이 금액과 규칙을 처리합니다. 공항 환급은 수령 전까지 예정액으로 구분하고, 매장 즉시환급은 차감된 구매가격에 반영합니다. 충전·ATM 원금은 소비에 중복 합산하지 않으며 금융비용만 반영합니다. 등록 당시 환율을 거래에 저장하므로 국가를 바꿔도 과거 거래의 금액은 유지됩니다.

검증:

```sh
node --test tests/core.test.cjs
node scripts/browser-check.mjs
```

계산 테스트 12개와 브라우저 검증 39개를 통과했습니다. 브라우저 검증은 macOS에 설치된 Google Chrome의 DevTools를 사용하고 별도 패키지를 설치하지 않습니다. 데스크톱 1440px, 모바일 390px, 태블릿 768px에서 화면 이동·계산 연결·중복 방지·저장 및 가로 넘침을 확인합니다.

공식 확인 경로: [프랑스 세관 PABLO 안내](https://www.douane.gouv.fr/en/fiche/tax-exemption-france-tourists-pablo), [우리카드](https://www.wooricard.com/), [우리은행](https://www.wooribank.com/). 실제 환급 적격 여부와 금융상품 조건은 해당 공식 채널에서 별도 확인해야 합니다.
