# Bonjour — 프랑스 여행 금융 도우미

`dist/index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치가 필요하지 않습니다.

- 여행 일정 검증 및 카드 유무에 따른 안내
- 위치·카드·도보 범위에 따른 가상 ATM 비교
- 같은 매장·같은 날 영수증 합산과 데모 환급 계산
- 지출 추가·삭제, 예산 계산, 도넛 차트
- 여행 금융 전용 규칙 기반 채팅

여행 설정, 영수증, 가계부는 브라우저 localStorage에 저장됩니다.
실시간 금융 데이터, 실제 AI, OCR, 은행 연결은 포함하지 않습니다. ATM 및 환급 수치는 시연용입니다.

## 로컬에서 실행하기

Python 3가 설치되어 있으면 별도 패키지 설치 없이 로컬 서버로 실행할 수 있습니다.

1. 터미널에서 프로젝트 폴더로 이동합니다. 현재 Mac의 작업 경로 기준 명령어는 다음과 같습니다.

   ```bash
   cd /Users/ksojung/Desktop/ITStudy/98_HACKATHON/france-finance-mockup
   ```

   다른 경로에 프로젝트를 내려받았다면 해당 경로로 이동합니다.

2. 프로젝트 폴더에서 로컬 서버를 실행합니다.

   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
   ```

3. 브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)에 접속합니다. 실행 중에는 터미널을 열어 둡니다.

4. 서버를 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

여행 설정, 영수증, 가계부 데이터는 브라우저에 저장됩니다. 같은 브라우저와 같은 주소로 다시 접속하면 저장한 데이터가 유지됩니다.

서버 없이 화면을 간단히 확인하려면 Finder에서 프로젝트의 `dist/index.html`을 더블클릭해 브라우저로 열어도 됩니다.
