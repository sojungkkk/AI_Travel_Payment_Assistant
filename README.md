# 여행WON해 — 해외여행 금융 도우미

여행 국가·기간·예산·보유 카드를 바탕으로 **현금 확보, 결제, 택스 리펀드, 지출 정산**까지 해외여행 중 발생하는 금융 선택을 한곳에서 비교해 주는 서비스입니다. 특정 국가에 한정하지 않으며, 여행 국가에 따라 통화·환급 조건·ATM 수수료 등을 달리 적용합니다.

프런트엔드는 `frontend/`의 React·Vite 앱입니다. 아래 실행 명령으로 개발 서버를 시작합니다.

## 서비스 구성

| 페이지 | 이름 | 목적 |
| --- | --- | --- |
| 1 | 여행 정보 및 맞춤 금융 가이드 | 국가·기간·예산·보유 카드에 맞는 금융서비스와 결제수단 안내 |
| 2 | AI 환전 및 ATM 최적화 | 환전소·ATM·외화충전을 실제 비용과 이동 부담까지 따져 비교 |
| 3 | AI Tax Refund 및 최종 결제비용 비교 | 영수증 분석, 환급 장소·시점 비교, 결제·환급 조합별 최종 실지출액 비교 |
| 4 | AI 여행 가계부 및 금융 최적화 리포트 | 현금·카드·환급 내역을 통합해 실제 원화 소비금액 분석 |

### 1. 여행 정보 및 맞춤 금융 가이드

- **여행 기본 정보 입력**: 여행 국가·도시, 기간, 예산, 보유 카드, 보유 현금, 해외결제용 외화계좌 보유 여부
- **보유 카드 선택**: 대분류(외화 트래블카드 / 일반 해외결제 카드 / 보유 카드 없음)를 복수로 고르고, 트래블카드는 카드를, 일반 해외결제 카드는 카드사 → 카드 순으로 고릅니다. 목록에는 해외 혜택이 있는 대표 카드만 두고, 없는 카드는 직접 입력합니다.
- **보유 카드 맞춤 안내**: 선택한 카드별 해외 혜택(예: 해외 가맹점 3% 적립, 해외 가맹점 이용 수수료 면제), 해외결제 가능 여부, 현지통화 결제와 해외원화결제(DCC)의 차이. 카드별 해외결제·ATM 수수료는 추후 추가합니다.
- **우리금융 서비스 연계**: 우리카드·우리은행의 해외결제·외화환전 상품 안내, 보유 카드와의 비용 조건 비교, 외화계좌 충전 및 카드 사용 가능 여부, 공식 서비스 페이지 연결
- **공통 AI 금융 챗봇**: "현금과 카드 중 무엇이 좋을까?", "이 카드의 해외결제 수수료는?", "이 영수증, 공항에서 환급받아야 해?" 같은 질문에 답합니다. 전 페이지 공통으로 동작하며 영수증 분석 결과와 환급 비교 결과도 근거로 참조합니다. 확인되지 않은 정보는 단정하지 않고 '확인 필요'로 안내합니다.

### 2. AI 환전 및 ATM 최적화

- **환율·환전 금액 계산기**: 현지통화↔원화 환산, 환전소별 환율·수수료 비교, ATM 카드사·현지 운영사 수수료, 예상 수령액과 총비용, 정보 출처·조회 시각 표시
- **주변 환전소·ATM 지도**: 위치, 영업시간, 취급 통화, 확인된 수수료, 거리·예상 이동시간, 영업시간 외 이용 조건
- **AI 현금 확보 경로 추천 (핵심)**: "지금 방콕인데 현금 3,000바트가 필요해. 트래블카드가 있고 원화 현찰 10만 원도 있어."처럼 자연어로 상황을 입력하면 위치·카드·현금·필요 금액을 추출하고, 부족한 조건은 되묻습니다. 이후 ATM·환전소·우리금융 외화충전 대안의 총비용을 검증된 환율·수수료로 계산해 비용·거리·영업시간 기준으로 비교하고, 추천 이유와 주의사항을 설명합니다.
- **우리금융 연계 대안 비교**: 외화계좌 충전 후 ATM 인출(대안 A), 충전 후 카드결제로 필요한 현금 자체를 줄이는 방안(대안 B)을 현지 환전소·ATM과 비교하고, 확인된 조건에서 더 유리하면 "약 N원 절감" 형태로 제시합니다.
- **AI 현장 환율표 분석**: 환율표 사진을 올리면 Vision AI가 매입·매도 환율과 수수료를 추출하고, 사용자 확인 후 비용 계산에 반영합니다.

> 환율과 수수료가 확인되지 않은 업체는 최저비용으로 단정하지 않습니다. 우리금융 대안도 확인된 조건에서만 비교하며 항상 유리하다고 단정하지 않습니다.

### 3. AI Tax Refund 및 최종 결제비용 비교

- **영수증·환급서류 분석**: 영수증 사진·PDF에서 구매 국가, 매장명, 날짜, 금액, VAT를 추출하고 택스 리펀드 서류 발급 여부, 매장 즉시환급 적용 여부, 구매 내역과 서류 간 거래 매칭을 확인합니다.
- **택스 리펀드 조건 확인**: 국가별 최소 금액·자격 조건, 환급 가능 여부 점검 항목, 예상 환급액, 세관 확인 및 출국 전 준비사항
- **환급 장소·시점 비교**: 매장 즉시환급, 공항·출국 시점 환급, 시내 환급 창구 등을 수수료 차감 후 환급액, 수령 시점, 필요 서류, 이동 동선·대기 부담, 수령 방식, 사후 절차 기준으로 비교해 가장 유리한 방법과 대안과의 차이를 보여 줍니다.
- **최종 실지출액 비교 (핵심)**: 현지 현금 환전(A안) / 외화 트래블카드(B안) / 일반 해외결제 카드(C안) 결제와 환급 장소·시점·수령 방식을 조합해 환전소 환율·수수료, 외화 충전 환율, 카드 해외결제 수수료, 환급 수수료, 환급금 수령 환율을 반영한 **환급 후 최종 원화 지출액**을 비교합니다.
- **AI 환급 경로 안내**: 출국 공항과 EU 최종 출국 국가 확인, 세관 확인 장소·공식 안내 연결, 서류 누락 점검, 매장·출국 전·공항 단계별 체크리스트
- **우리금융 환급 관리 연계**: 우리카드 환급 절차, 환급 예정액과 실제 거래내역 비교, 외화계좌 수취 지원 여부, 환급되지 않았거나 예상과 다른 거래 표시

> 국가·환급사업자·매장별 지원 여부가 확인되지 않은 방식은 비교에서 제외하거나 '확인 필요'로 표시합니다. 외화계좌 자동 입금은 보장하지 않습니다.

### 4. AI 여행 가계부 및 금융 최적화 리포트

- **지출내역 통합**: 환전·ATM 인출(우리금융 외화충전 포함), 카드결제, 영수증 구매 내역, 환급 예정액·실제 환급액을 합치고 중복 거래를 자동 매칭합니다.
- **AI 소비 카테고리 분류**: 음식, 쇼핑, 교통, 숙박, 관광, 기타
- **시각화**: 카테고리별 지출 비율, 예산 대비 사용률, 현금·카드 비율, 환전·카드결제 총수수료, 환급 수령 현황
- **AI 여행 금융 리포트 (핵심)**: 총지출, 환전·카드결제 비용, 환급받은 금액, 환급 후 최종 원화 지출액, 확인된 대안 대비 절감 가능했던 금액, 선택한 환급 방식과 우리금융 대안의 사후 비교, 다음 여행을 위한 금융 정보를 제공합니다.

## AI 처리 흐름

| 단계 | 담당 | 내용 |
| --- | --- | --- |
| 입력 | 사용자 | 여행 정보 + 보유 카드 + 영수증·환율표 + 확인 가능한 금융상품 데이터 |
| 해석 | AI | 자연어 상황 파악 → 이미지·문서 인식 → 거래 매칭 → 부족한 정보 추가 질문 → 환급 질문 응답 |
| 계산 | 일반 계산 엔진 | 환율·수수료·환급 조건 계산 → 현금 확보 경로와 환급 장소·시점별 최종 비용 비교 |
| 결과 | 서비스 | 최적화된 금융 선택지 + 예상 절감액 + 이용 경로 + 지출 리포트 |

AI는 정보의 해석·분류·연결을 담당하고, 금전 계산과 규칙 검사는 검증된 프로그램으로 수행합니다.

## 데이터와 한계

여행 설정, 영수증, 가계부는 브라우저 localStorage에 저장됩니다.
실시간 금융 데이터, 실제 AI, OCR, 은행 연결은 포함하지 않습니다. ATM 및 환급 수치는 시연용이며, 은행·고객·금액은 모두 가상입니다.

## 로컬에서 실행하기

현재 프런트엔드는 React·Vite 기반 목업입니다. 백엔드 서버나 DB를 실행하거나 `.env`에 API 키를 설정하지 않아도 화면과 시연 기능을 사용할 수 있습니다.

1. **실행 환경 확인**

   Node.js **22.12 이상**과 npm이 필요합니다. 터미널에서 설치된 버전을 확인합니다.

   ```bash
   node --version
   npm --version
   ```

2. **프런트엔드 폴더로 이동**

   아래 명령은 저장소 루트인 `my-hackathon/`에서 실행합니다. 현재 위치가 상위 `98_HACKATHON/`이라면 먼저 `cd my-hackathon`을 실행합니다.

   ```bash
   cd frontend
   ```

3. **의존성 설치 및 개발 서버 실행**

   처음 실행하거나 `package.json`·`package-lock.json`의 의존성이 변경된 경우 설치한 뒤 실행합니다.

   ```bash
   npm ci
   npm run dev
   ```

   이후 같은 환경에서 다시 실행할 때는 `frontend/`에서 다음 명령만 실행하면 됩니다.

   ```bash
   npm run dev
   ```

4. **브라우저 접속**

   기본 주소는 [http://127.0.0.1:5173](http://127.0.0.1:5173)입니다. 실제 접속 주소는 터미널에 출력되는 `Local` 항목을 확인합니다.

   여행 정보, 환전·ATM, 택스 리펀드, 여행 가계부를 확인할 수 있으며, 개발 중 소스 변경 사항은 화면에 자동 반영됩니다.

5. **종료**

   서버를 실행한 터미널에서 `Ctrl + C`를 누릅니다.

개발 서버는 `frontend/index.html`을 진입점으로 사용합니다. 배포용 파일은 별도의 `npm run build` 명령으로 `frontend/dist/`에 생성하며, 자세한 명령은 아래 [빌드와 검증](#빌드와-검증)을 참고합니다.

여행 설정, 영수증, 가계부는 브라우저 localStorage에 저장됩니다. 기존 저장 키와 데이터 형식은 유지하며, 같은 브라우저와 같은 주소(프로토콜·호스트·포트)에서 기존 기록을 불러올 수 있습니다. 이전에 다른 포트에서 사용한 데이터는 자동으로 옮겨지지 않습니다.

## 프런트엔드 구조

[WONIT-A/05_springAI의 frontend](https://github.com/WONIT-A/05_springAI/tree/main/frontend)를 참고해 현재 화면에 필요한 파일만 구성했습니다.

```text
frontend/
├── index.html
├── package.json
├── package-lock.json
├── vite.config.js
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── App.css
    ├── components/
    │   ├── Layout.jsx
    │   ├── TripPage.jsx
    │   ├── CashPage.jsx
    │   ├── RefundPage.jsx
    │   ├── BudgetPage.jsx
    │   └── ChatBot.jsx
    ├── hooks/
    │   ├── useTravelState.js
    │   └── useFilePreview.js
    └── utils/
        ├── core.js
        └── format.js
```

`App.jsx`에서 화면 전환과 공유 상태를 연결하고, 계산은 `utils/core.js`, 브라우저 저장은 `hooks/useTravelState.js`가 담당합니다.

## 빌드와 검증

`frontend/`에서 실행합니다.

```bash
npm test
npm run build
npm run preview
```

`npm run build`는 배포용 파일을 `frontend/dist/`에 생성합니다. 의존성 폴더와 빌드 결과는 Git에서 제외합니다. 호스팅 설정은 이 빌드 결과를 가리킵니다.

브라우저 검증은 macOS에 설치된 Google Chrome으로 화면 전환, 환급·가계부 연동, 중복 방지, 저장 복원과 반응형 화면을 확인합니다.

```bash
npm run test:browser
```

저장소 루트의 `.env`는 프런트엔드에서 읽지 않습니다. 필요한 프런트엔드 설정은 `frontend/.env.local`의 공개 가능한 `VITE_` 변수로만 지정하고, 비밀 값은 백엔드 환경변수로 관리합니다.
